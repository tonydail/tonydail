Microservices

Overview: This microservices project provides an authentication and user management system built with modern event-driven architecture patterns. The services are designed to be forked and tailored for specific use cases, providing a solid foundation for authentication and user profile management that teams can customize to their needs.

Solution: Event-driven microservices platform for authentication and user management built with Node.js/TypeScript. Features transactional outbox pattern with Debezium CDC, hybrid REST/gRPC communication, Kafka event streaming, JWT-based auth, and nginx API gateway. Production-ready architecture with layered design, Dev Container support, and comprehensive testing. Designed to be forked and tailored for specific use cases.

Technologies:

Apache Kafka message broker RPC Docker Development Containers Nginx Node.js Express PostgreSQL TypeScript Microservices RESTful APIs Event-driven Architecture Debezium CDC Zod Schemas
