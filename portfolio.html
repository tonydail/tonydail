Microservices

Overview: This microservices platform demonstrates event-driven architecture through an authentication and user management system. Built as a showcase of modern distributed systems patterns, it implements enterprise-level practices including transactional outbox with CDC, hybrid communication protocols, and containerized development workflows. The project serves as both a functional system and a reference implementation for teams building scalable microservices architectures.

Solution: Event-driven microservices platform featuring JWT-based authentication and user profile management. Implements transactional outbox pattern with Debezium CDC for guaranteed event delivery, hybrid REST/gRPC communication for optimal performance, and nginx API gateway with JWT validation. Architecture emphasizes strict layered design, idempotent event processing, and zero-downtime operation. Includes comprehensive Dev Container setup for consistent development environments, automated connector registration, and full CI/CD pipelines with unit and integration testing.

Technologies

  • Backend: Node.js, TypeScript, Express.js, gRPC (@grpc/grpc-js)

  • Database: PostgreSQL, Prisma ORM

  • Event Streaming: Apache Kafka (KRaft mode), Debezium CDC, Kafka Connect

  • API Gateway: nginx with JWT validation

  • Security: JWT (access + refresh tokens), bcrypt password hashing

  • Development: Dev Containers, Docker, Docker Compose

  • Testing: Vitest (unit + integration), GitHub Actions CI/CD

  • Code Quality: ESLint, Prettier, TypeScript strict mode

  • Validation: Zod schemas

  • Logging: Pino structured logging

  • Monitoring: Kafka UI, CloudBeaver (database UI)
